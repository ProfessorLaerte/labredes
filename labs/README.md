# Histórico de Laboratórios e Materiais Anteriores

Este diretório contém os roteiros, materiais e modelos utilizados em semestres anteriores da disciplina **ENE0011 – Laboratório de Redes**.

> **Nota:** Estes materiais são mantidos aqui apenas para fins de consulta e arquivo histórico. Para os roteiros e experimentos vigentes, consulte a pasta [`laboratorios/`](../laboratorios/).

### Conteúdo deste diretório:
- **`lab-01.md` a `lab-11.md`**: Roteiros das práticas antigas (Dispositivos, Sniffers, VLANs, RIP, OSPF, Ataques ao OSPF e BGP).
- **`comandos.md`**: Guia rápido de comandos OSPF.
- **`VM-Cybersecurity.md`**: Lista e orientações sobre máquinas virtuais para práticas de segurança.
- **`relatorio.md`**: Cópia do modelo histórico de relatório.
- **`arquivos/`**: Arquivos de topologia antigos (ex.: `Exp-08 -Vlan_configurado.pkt`).
